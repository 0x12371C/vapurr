# vapurr brand

Spec: `assets/brand-board.png`. The UI is **drawn from that board**. We do not blit the PNG into the chrome.

**VAPURR** — all caps in the product. The mark is a **cat**, not a fox. Vapor + purr.

## Voice

Short. Sovereign. No BAT. No seed-phrase theatre.

Tagline: **BROWSE. OWN. SPEND.**

Domain: vapurr.com

## Type

**Sora.** Wordmark SemiBold. UI Regular. Tracking slightly open on VAPURR.

## Mark

Geometric cat head, lime stroke, void fill. Pointed ears, inner-ear notches, almond eyes filled lime, sharp chin. Drawn as paths in `vapurr_ui::cat`. Never a raster stamp of the board.

## Iconography (line, lime)

Bolt · wallet · **404** · card · shield · swap · lock · phones · chart · grid

## Surfaces

- Home: giant VAPURR, command search, tiles (Wallet, Swap, Stake, Bridge, PUSD, vapurrbid, PNS, Live Trenches, Scan, dApps)
- Sidebar: cat + home, wallet, PUSD, Live Trenches, scan, history, bookmarks, earn, zzzmail, settings, theme, shield
- Card: black Visa, cat mark, VAPURR BY AVALANCHE — drawn, not a photo
- Pay sheet: **KetPay**. Wire is HTTP 402 / x402. 404 is load-fail only.

Fast. Sovereign. Seamless. Unstoppable.
