# vapurr v1

We are **pre-v1**. Everything in this tree is aimed at one ship: a Windows zip a stranger can unzip and browse with.

v1 is a **browser with vapurr chrome and Robinhood Chain in the product**. It is not Servo. It is not live card KYC. It is not a protocol demo that cannot open google.com.

North star after v1 is still Servo, native wallet authority, x402, zmail, zer0ID, Rain passthrough. Those crates stay in the workspace and keep compiling. They are not the v1 critical path.

## What v1 is

A person double-clicks `dist\vapurr\vapurr.exe` and gets:

1. A native Windows window that looks like `DESIGN.md` (cat, lime from `frontend/tokens.css`, Sora).
2. Real https browsing in the page webview. **WebView2 is allowed for v1.** Do not rip it out to "be pure."
3. Chrome that is not a website: rail, toolbar, tabs, home, settings persisted in `desk.json`.
4. **Shield** actually blocking ads/trackers before paint.
5. **Scan** live against Robinhood Chain (`vapurr-rhc`), including the **liquidity graph** (entire-chain pools as the market data source).
6. **Live Trenches** opens **https://fomo.family** in this window (rail, home tile, `vapurr://fomo` / `vapurr://family`). Ketflix stays a separate chrome surface (`vapurr://ketflix`).
7. **$VAPURR / $PUSD** desk talks to **PusdMarket on Robinhood Chain**. Burn V mint P, burn P mint V. **Lithe** (`vapurr://lithe`) is 9% on `$PUSD`. Deploy from the desk.
8. Bookmarks, history, cookies, Boost/blob cache, Maestro radio.
9. **vapurrbid** (`vapurr://vapurrbid`) — $PUSD pay-to-rank. Aliases `outbid` / `bid` / `board`.
10. **PNS** (`vapurr://pns`) — Purr Name Service, TLD `.hood`. On-chain registry. Aliases `hood` / `names`.
11. `.\pack.ps1` produces `dist\vapurr-<ver>-windows-x64.zip`. Double-click **Install vapurr.exe** — branded first-run, no admin. `cargo test --workspace` is green. The on-chain market is not a gate to browse.

## What v1 is not

These wait until after v1.

| After v1 | Why it waits |
|---|---|
| Servo as the page engine | Guest is Edge until libservo is pinned. Feature `servo` is a compile error on purpose. |
| FetcherEngine as the user's browser | Protocol/reader crate. The window still navigates Edge. |
| egui chrome (`vapurr-ui`) | Leftover. Not linked by the shell. |
| Live Rain / Avalanche Card | No PAN, no live issuer secrets in tree. Card pane is a drawn plate. |
| Live zer0ID issuer | Simulator only. `vapurr://id` is a parked honest sheet. No issuer, no KYC form. |
| x402 settlement from the 404 sheet | Sheet is chrome. Pay currently jumps to the card pane. |
| zmail send/receive | Glass inbox. Send seals, pins a CID, signs a 0.25¢ $PUSD/$VAPURR voucher (0 ETH). Body never on-chain. Postage settlement waits on the live market. |
| One site-process per eTLD+1 + freeze | Types in `vapurr-core`. Guest is one Edge profile. |

## Honest skins (v1 may ship these as chrome)

These URLs must exist and match brand. They must **not** fake a successful payment, KYC, or mail send.

| Surface | v1 bar |
|---|---|
| `vapurr://wallet` | Glass portfolio for this device on Robinhood Chain. Live Trenches is a separate tab. |
| `vapurr://pay` (404) | Explains 402/x402. Does not settle. |
| `vapurr://card` | Drawn VAPURR card. No Rain. |
| `vapurr://zzzmail` (`zmail`, `mail`) | iMessage-style glass inbox. `.hood` names. Send pins a CID and a gasless 0.25¢ voucher. Does not claim on-chain settlement until the market is live. |
| `vapurr://swap` / `vapurr://bridge` | LI.FI quotes are live. CTA copies the route and opens Wallet. Does not settle on-device. |
| `vapurr://id` | Parked zer0ID sheet. Prove a person, handle not passport. Does not talk to an issuer. Ad block is `vapurr://shield`. |
