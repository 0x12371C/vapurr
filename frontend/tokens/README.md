# Token marks

| File | What | Source |
|---|---|---|
| `eth.svg` | ETH diamond in a circle | Ethereum Foundation brand diamond (`ethereum.org/assets`), paths from the Wikimedia Commons copy of that mark |
| `weth.svg` | Same diamond, ringed | WETH is wrapped ether — official ETH glyph |
| `usdg.svg` | Green-on-green G | Global Dollar token colorway from [globaldollar.com/brand](https://globaldollar.com/brand) (Paxos / GDN). Partners are asked to use this mark |
| `pusd.svg` | Lime **P** | House mark for `$PUSD` |
| `/mascot.png` | Cat | `$VAPURR` |
| `amzn.svg`, `tsla.svg`, `amd.svg`, `nflx.svg`, `pltr.svg` | Amazon, Tesla, AMD, Netflix, Palantir brand marks | [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons), vendored with `scripts/fetch-route-icons.py`; upstream CC0, trademarks remain with their owners |

gV/wgV use the VAPURR cat with distinct token labels. Stock logos identify the underlying brand; they do not authenticate a token contract. Router identities use chain ID and contract address.

Do not use Trust Wallet’s `0x1aBa…` USDG file — that asset is a euro mark, not Global Dollar.
