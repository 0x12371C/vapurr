# vapurrbid

Pay-to-rank on the home floor. Rank is $PUSD paid. Nothing else.

| Rule | Number |
|---|---|
| First listing | 10 $PUSD |
| To take #1 | current top + 5 $PUSD |
| Raise | +1 $PUSD minimum, you only pay the difference |
| Cap | 999,999 $PUSD |
| Listings | 256 |
| Refunds | none |
| Expiry | none |

The pot stays in the contract. Same URL stays with the first bidder. Only that bidder can raise.
