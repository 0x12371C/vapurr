# Browse

Type a URL. It opens here.

Shield (the shield on the rail) kills ads and trackers before the page shows. That’s ad block — not identity.

Star pages, history, and cookies are in the rail.

`vapurr://earn` seals browsing receipts: host, HTTPS, time. No path. A session on the same host counts once (30 minutes). Seal writes a hashed window. KYC is for payout, not for the paper.
