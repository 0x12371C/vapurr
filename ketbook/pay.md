# KetPay

Pay any site. The screen is **KetPay**. The wire is HTTP **402** / x402 v2. **404** is a page that failed to load — not this.

The dollar in the window is **$PUSD**. If the site’s accept list is Robinhood testnet `$PUSD` (`eip155:46630`), that is the plan. If they only list USDG on that net, USDG. Visa-shaped merchants go through the card passthrough. vapurr never stores a card number.

KetPay signs on this device and sends `$PUSD` on **testnet 46630**. It does not settle on mainnet.
